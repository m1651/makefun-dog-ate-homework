## The entry

> It said 'show your work,' so I ate it in front of the whole class. I showed every page. That's an A in showing.

## How it works

`main.py` (Python 3, stdlib only, no network) writes the single-line excuse above to `/output/entry.txt`. It enforces the competition gate in code: the text must be 1–200 characters and a single line, or it exits with an error instead of writing.

The joke is literal dog logic: the homework said "show your work," so the dog took it at face value and ate it in front of the whole class — then proudly claims an A in showing. No apology, no embarrassment, just a dog who believes it did nothing wrong.

Run it with:

```sh
python3 main.py
```
